*mdw.txt*  Markdown workspace tools

Author: lmdevv
Version: 0.0.1
License: MIT

mdw searches notes, follows links, and edits lists and frontmatter. Optional
tools add formatting, diagnostics, rendering, and Obsidian. This plugin does
not include a personal Neovim configuration.

==============================================================================
SETUP                                                            *mdw.setup()*

>lua
  require("mdw").setup({
    workspace = { root = nil },
    search = { enrich_files = false },
    notes = { extensions = { "md", "markdown", "mdc", "mdx", "mkd" } },
  })
<

Calling setup again replaces the configuration and refreshes commands and
autocmds without duplicating them.

mdw does not set leader mappings. See |mdw-compatibility| for the Neovim
version and optional tools.

==============================================================================
COMMANDS                                                            *mdw-commands*

:mdw                         Show command usage.
:mdw health                  Run |:checkhealth| for mdw.
:mdw search [query]          Search notes in the current workspace.
:mdw index                   Rebuild the current workspace index.
:mdw follow                  Follow the link under the cursor.
:mdw sidebar                 Open the note sidebar.
:mdw outline                 List headings in the quickfix.
:mdw backlinks               List backlinks in the quickfix.
:mdw outgoing                List outgoing links in the quickfix.
:mdw qf {view}               Fill the quickfix. View is outline,
                             backlinks, or outgoing.
:mdw trouble {view}          Show that list in Trouble when installed.
:mdw rename {path}           Move a note and update references.
:mdw new {path}              Create a note. template= and backend=
                             are optional.
:mdw daily [...]             Open a daily note.
:mdw dailies [query]         Search daily notes.
:mdw property {key} {value}  Set one frontmatter property.
:mdw aliases {names}         Replace aliases.
:mdw tags {names}            Replace tags.
:mdw obsidian                Open the current note in Obsidian.
:mdw format                  Format the buffer with rumdl.
:mdw lint                    Publish rumdl diagnostics.
:mdw image                   Paste a clipboard image.
:mdw list continue           Continue the current list item.
:mdw list nest               Indent the item one level.
:mdw list unnest             Outdent the item one level.
:mdw list check              Toggle a checkbox.

==============================================================================
WORKSPACE                                                          *mdw-workspace*

The workspace is the git toplevel of the file in the current window. A file
that is not inside a git repository uses that file's directory. An unnamed
buffer uses the current working directory the same way.

`workspace.root` pins one directory and skips discovery. A relative root is
resolved from the current working directory. Switching to a buffer from
another repository switches the workspace used by search.

Dot-directories and `node_modules` are not indexed. Notes are files ending in
`.md`, `.markdown`, `.mdc`, `.mdx`, or `.mkd`.

==============================================================================
INDEX                                                                  *mdw-index*

Opening, searching, and indexing do not write notes. A malformed note is
skipped, reported by health, and does not stop the rest of the workspace from
indexing.

Title is the frontmatter string `title` when present, otherwise the first ATX
heading, otherwise the filename stem. Aliases come from `aliases` or `alias`.
Tags come from `tags` or `tag`, plus inline `#tags` outside fenced code,
inline code, and link destinations. A wikilink label is not an alias. The
same scan is used for every supported extension, so a `#` inside JSX can be
indexed as a tag.

Frontmatter support is a YAML subset: scalars, flow lists, and block lists
for the keys above. Other keys are ignored when their lines fit that subset.
Unclosed frontmatter and unsupported lines skip the file.

Open modified buffers are indexed from buffer text, including unsaved edits.
Unmodified files are indexed from disk. `:mdw index` rebuilds the workspace.
Entering an unmodified buffer refreshes that note when the file on disk has
changed.

==============================================================================
SEARCH                                                                *mdw-search*

`:mdw search` uses the picker named by `search.picker`. `auto` uses
|mini.pick|, then Snacks (`snacks.picker`), then Telescope, and
|vim.ui.select()| when none of those is installed. Set `search.picker` to
`mini`, `snacks`, `telescope`, or `select` to choose one. A missing explicit
picker falls back to |vim.ui.select()| and is reported by |:checkhealth|.
The note list keeps mdw's ranking. The query may contain text and `#tag`
filters.
Every tag filter must match exactly, ignoring case. `#parent` does not match
the tag `parent/child`.

Text matches a substring of the path, filename, title, aliases, or tags.
Every text token must match. Matching ignores case until the query contains
an uppercase letter. Tag filters stay case-insensitive either way.

Rank, from strongest to weakest:

1. Exact title or alias
2. Prefix of a title or alias
3. Other substring of a title or alias
4. Filename
5. Path
6. Tag only

Each row is tab-separated: path, then title, then aliases, then tags.
A title taken from the filename is omitted, and an empty aliases or tags
field is omitted. Each physical note appears once. An empty query lists the
notes in the current workspace.

`search.enrich_files` defaults to false. When true, file search from
mini.pick, Snacks, and Telescope matches note metadata while its directory
is inside the workspace. A file whose name does not contain the query still
appears when the title, alias, or tag does. File search outside the workspace
is unchanged. Set the option back to false and call setup to restore the
previous picker functions.

Full-content search is a separate action and is not implemented here.

==============================================================================
NAVIGATION                                                        *mdw-navigation*

`gd` on a Markdown link, wikilink, or URL follows that link. A unique note
opens at the heading or block when the link has one. Several matches open a
chooser. A missing note asks before creating a file. A missing heading or
block opens the note and reports that the location is missing. `gd` away from
a link uses the attached LSP.

`:mdw sidebar` opens the outline. In that window, `o` shows the outline, `b`
shows backlinks, `l` shows outgoing links, Enter jumps, and `q` closes it.
`:mdw outline`, `:mdw backlinks`, and `:mdw outgoing` fill the quickfix list.
`:mdw qf {view}` does the same. `:mdw trouble {view}` uses Trouble when it is
installed, and the quickfix list otherwise.

`:mdw rename {path}` previews references, then updates wikilinks and Markdown
links and moves the file. The destination must be free. A note with unsaved
changes is left untouched.

==============================================================================
CREATE                                                            *mdw-create*

`:mdw new {path}` asks, then writes a note. `:mdw daily` opens today's note,
creating it only when it is missing. `:mdw daily yesterday`, `tomorrow`,
`prev`, `next`, or `YYYY-MM-DD` select another day. `prev` and `next` open an
existing daily note and do not create one. The default name is `YYYY-MM-DD.md`.
`daily.folder`, `daily.format`, and `daily.template` override the vault.
When `.obsidian/daily-notes.json` exists, its folder, format, and template
fill any daily option left unset. Set `obsidian.import_daily` to false to
ignore that file. An imported format other than `YYYY-MM-DD` is reported and
not guessed.

`:mdw dailies` opens the note picker with only those daily notes. A query uses
the same matching as `:mdw search`.

`:mdw property {key} {value}`, `:mdw aliases {names}`, and `:mdw tags {names}`
edit frontmatter in place. Comments, unknown keys, and the body stay put.
A multiline YAML value is left unchanged and reported.

`create.backend` stays `local` when the workspace contains `.obsidian`.
`local` writes the file in Neovim. `obsidian` lists templates with
`obsidian templates` and creates with
`obsidian vault={workspace} create path={file}` without a shell.
`:mdw new {path} backend=obsidian` and `:mdw daily backend=local` override
that for one command. `:mdw obsidian` opens the current note in the app.
Local commands keep working when the CLI is absent.

Templates come from the folder in `.obsidian/templates.json`. Entries in
`create.templates` add or replace a template by name. One available template
is used on its own. Several templates open a picker, which includes a blank
note. `:mdw new {path} template={name}` skips the picker.
`create.default_template` also skips it. Template text may contain
`{{title}}`, `{{date}}`, `{{time}}`, and `{{date:YYYY-MM-DD}}`. Any other
`{{field}}` is copied through and reported.

==============================================================================
HEALTH                                                                *mdw-health*

:checkhealth mdw

Reports the Neovim version, workspace root, note count, skipped files,
the note-search picker, file-search enrichment, Obsidian, rumdl,
rendering, and markdown-oxide.

EDITING                                                            *mdw-editing*

:mdw format              Format the buffer with rumdl
:mdw lint                Show rumdl diagnostics
:mdw image               Paste a clipboard image
:mdw list continue       Continue the list item
:mdw list nest           Indent the item one level
:mdw list unnest         Outdent the item one level
:mdw list check          Toggle the checkbox

Format on save is off by default. A failed format leaves the buffer unchanged.
Images are written beside the note in `assets/` and do not replace an
existing file.

List commands work on `-`, `*`, `+`, and numbered items. `continue` from the
end of an item inserts the next item. From the middle of the text it splits
there. An empty item unnests once. A top-level empty item becomes a blank
line. A continued checkbox is unchecked, and a numbered list renumbers the
following siblings. `nest` and `unnest` keep the marker. A numbered child
starts at 1, and unnesting it rejoins the parent numbering. `check` switches
`[ ]` and `[x]`. On a list item with no box it adds `[ ]`. A range, including
a reversed visual selection passed as a command range, covers each selected
line. Fenced lines are left unchanged.

mdw does not map these commands. Set `lists.maps` to bind `continue` in
insert mode, `open` in normal mode, and `nest`, `unnest`, and `check` in
normal and visual mode. `lists.level` is the number of spaces in one nesting
level. The default is 2. A tab-indented item nests by one tab.

`render.enabled` configures `render-markdown.nvim` once when it is installed.
`lsp.enabled` attaches `markdown-oxide`. `lsp.rename` gives rename to that
server, and `:mdw rename` then leaves the files alone.

Browser preview is not in this release.

==============================================================================
COMPATIBILITY                                                *mdw-compatibility*

Neovim 0.11 or newer. Tests run on Neovim 0.12 on x86_64-linux. mdw is Lua
and does not ship a binary, so it does not need a separate build per system.

Git finds the workspace toplevel. Without git, the workspace is the current
file's directory. `workspace.root` skips that lookup.

Optional tools. Setup still succeeds when one is missing:

	mini.pick, snacks.nvim, telescope.nvim
		Note search and the link chooser. |vim.ui.select()| is the
		fallback.
	rumdl
		`:mdw format` and `:mdw lint`. Format-on-save stays off.
	wl-paste or xclip
		`:mdw image` on Linux. Set `edit.clipboard` to another argv
		list on other systems.
	render-markdown.nvim
		In-buffer rendering when `render.enabled` is true.
	markdown-oxide
		LSP when `lsp.enabled` is true.
	Obsidian CLI
		Template list and creation when `create.backend` is
		"obsidian", and `:mdw obsidian`. Daily-note search and
		local templates read `.obsidian` without the CLI.
	Trouble
		`:mdw trouble` only.

`:mdw image` tries `wl-paste`, then `xclip`. That default is the Linux
clipboard. Another system sets `edit.clipboard`, for example
`{ "pngpaste" }`.

NIXVIM                                                              *mdw-nixvim*

The flake output `nixvimModules.default` is a NixVim module. Import it from
the NixVim configuration:

>nix
  programs.nixvim = {
    imports = [ inputs.mdw.nixvimModules.default ];
    plugins.mdw = {
      enable = true;
      settings = { };
      extraPackages = [ pkgs.rumdl ];
    };
  };
<

`settings` is passed to |mdw.setup()|. `extraPackages` is added to Neovim's
PATH. mdw does not download those packages. NixVim does not ship this
plugin. Import `nixvimModules.default` from this flake.
